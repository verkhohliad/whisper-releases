# Whisper releases

Public downloads for **Whisper**, a free local dictation and voice companion for Apple silicon Macs.

- [Product site](https://whisper.1step.ink/)
- [Download the latest release](https://github.com/verkhohliad/whisper-releases/releases/latest)
- [Privacy](https://whisper.1step.ink/privacy/)
- [Support](https://whisper.1step.ink/support/)

Every published DMG is Developer ID signed, Apple notarized, and accompanied by a SHA-256 checksum in its release notes.
